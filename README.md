# 単振動シミュレータ

高校物理「単振動」の学習用 Web アプリです。公開ページ：https://shin-phys.github.io/harmonic_motion/

| モード | 内容 |
|---|---|
| 1 円運動から単振動へ | 等速円運動 → y 軸への投影 → ばね振り子 → y-t 図 → 速度・加速度 → エネルギー（8 ステップ） |
| 2 位相と式の理解 | 初期位相 φ と式 y = A sin(ωt + φ)、y-t・v-t・a-t 図 |
| 3 二つの振動の比較 | 質量・ばね定数・振幅を変えて周期をくらべる（等時性）、位相差 |
| 4 鉛直ばね振り子 | 自然長 → つり合いの位置（d = mg/k）→ 振動の中心 → 水平ばねと同じ周期（4 ステップ、力の表示） |
| 5 エネルギーのグラフ | U = ½kx² の放物線と E 一定の直線を、おもりの位置とそろえて表示。いまの K と U を長さで読む |
| 6 単振り子 | 運動方程式を数値計算し、単振動とみなした動きとくらべる。振れ角と周期の関係、T₀ = 2π√(L/g) |
| 7 摩擦のある振動（発展） | 動摩擦による振動の中心のずれと、振幅の直線的な減少 |
| 8 式を読み取る練習 | y-t 図から A・T・φ を読み取る（基本／発展）。答え合わせで自分の答えの曲線を重ねる |

鉛直のばね振り子では、振動の中心は「つり合いの位置」として表示しています。

## 画面の配置

- PC（幅 1024px 以上）：図と操作パネルを左右に並べ、スクロールせずに使える 1 画面の配置
- スマホ縦向き：図の下に操作パネル、再生・リセット・速度は画面下に固定
- スマホ横向き：図と操作パネルを左右に並べる

図は 800×500（Mode 3・4 は 800×560）の座標で描き、表示枠に合わせて拡大・縮小します（`src/components/CanvasFrame.jsx`）。

## 開発

```bash
npm install
npm run dev
npm run build   # main への push で GitHub Pages に自動デプロイ
```
